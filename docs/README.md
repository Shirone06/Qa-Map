# ระบบเช็คอินพนักงานนอกสถานที่ — หน้าเว็บ

หน้าเว็บทั้งหมดของระบบ ออกแบบให้โฮสต์บน **GitHub Pages** (ฟรี + HTTPS)
คุยกับ Google Sheet ผ่าน API ที่อยู่ในโฟลเดอร์ [`Checkin-API/`](../Checkin-API/)

## ไฟล์

| ไฟล์ | หน้าที่ | ใครใช้ |
|------|---------|--------|
| `index.html` | เช็คอิน / เช็คเอาท์ | พนักงานที่ออกไซต์งาน |
| `dashboard.html` | สรุปรายงาน + แผนที่ + ตาราง + ส่งออก CSV | หัวหน้างาน |
| `admin.html` | เพิ่ม/แก้หน่วยงาน (ปักหมุดจากแผนที่) และรายชื่อพนักงาน | ผู้ดูแลระบบ |
| `config.js` | **ไฟล์เดียวที่ต้องแก้** — ใส่ลิงก์ API | — |
| `common.js` | เรียก API, จับ GPS, ย่อรูป + ประทับข้อมูลบนรูป | — |
| `style.css` | ธีมร่วมของทุกหน้า | — |
| `manifest.json` `sw.js` `icon-*.png` | ทำให้ติดตั้งลงหน้าจอโฮมได้เหมือนแอพ | — |

## วิธีติดตั้ง

### 1. ตั้งค่าลิงก์ API

ติดตั้งฝั่ง Apps Script ให้เสร็จก่อน (ดู [`Checkin-API/README.md`](../Checkin-API/README.md))
แล้วเอา URL ที่ลงท้าย `/exec` มาใส่ใน **`config.js`**

```js
var API_URL = 'https://script.google.com/macros/s/AKfyc.../exec';
var ORG_NAME = 'บริษัท ซี.ซี. คอนเทนท์ คอมเมอร์เชียล จำกัด';
```

### 2. เปิด GitHub Pages

1. push โค้ดขึ้น GitHub
2. ที่ repo → **Settings → Pages**
3. Source: **Deploy from a branch** · Branch: **main** · Folder: **/docs** → Save
4. รอสักครู่ จะได้ลิงก์

| หน้า | ลิงก์ |
|------|-------|
| พนักงาน | `https://shirone06.github.io/Qa-Map/` |
| หัวหน้า | `https://shirone06.github.io/Qa-Map/dashboard.html` |
| ผู้ดูแล | `https://shirone06.github.io/Qa-Map/admin.html` |

### 3. ใส่ข้อมูลตั้งต้น

เปิด **admin.html** → ใส่ `ADMIN_PIN` → เพิ่มหน่วยงานโดยปักหมุดบนแผนที่
(หรือกรอกในแท็บ `Locations` ของชีตโดยตรงถ้ามีพิกัดอยู่แล้ว)

รายชื่อพนักงานแนะนำให้คัดลอกจากระบบเดิมไปวางในแท็บ `Employees` ทีเดียว
จะเร็วกว่าเพิ่มทีละคน

### 4. แจกลิงก์ให้พนักงาน

ให้พนักงาน **เพิ่มไปยังหน้าจอโฮม** ครั้งเดียว แล้วเปิดจากไอคอนตลอดไป

- **Android**: เปิดใน Chrome → ปุ่ม **⋮** → *เพิ่มลงในหน้าจอหลัก*
- **iPhone**: เปิดใน Safari → ปุ่ม **แชร์** → *เพิ่มไปยังหน้าจอโฮม*

> ⚠️ **อย่าให้พนักงานเปิดลิงก์ค้างไว้ใน LINE**
> เบราว์เซอร์ในแอพแชทมักบล็อกการขอตำแหน่ง ทำให้เช็คอินไม่ได้
> — แอพจะตรวจจับให้และขึ้นเตือนพร้อมปุ่มเปิดในเบราว์เซอร์จริง

## แนวทางตั้งรัศมีแต่ละหน่วยงาน

| ประเภทสถานที่ | รัศมีที่แนะนำ |
|---|---|
| ออฟฟิศ / อาคารเดี่ยว | 100–150 ม. |
| อาคารสูง / ห้างสรรพสินค้า | 150–250 ม. |
| โรงงาน / ไซต์ก่อสร้าง | 300–500 ม. |

GPS มือถือคลาดเคลื่อนได้ 10–50 ม. ในที่โล่ง และมากกว่านั้นในอาคาร
จึงควรเผื่อไว้อย่างน้อย 50 ม. เสมอ — **ตั้งแคบเกินไปคือสาเหตุอันดับหนึ่ง
ที่พนักงานเช็คอินไม่ได้ทั้งที่อยู่หน้างานจริง**

ถ้าไซต์ไหนมีปัญหาซ้ำๆ ให้ดูคอลัมน์ *ระยะห่างเข้า(ม.)* และ *ความแม่นยำเข้า(ม.)*
ในชีต `CheckLog` แล้วปรับรัศมีของจุดนั้นให้เหมาะ

## แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ขึ้น "ยังไม่ได้ตั้งค่า API_URL" | ยังไม่ได้แก้ `config.js` |
| ขึ้น "เชื่อมต่อเซิร์ฟเวอร์ไม่สำเร็จ" | ลิงก์ต้องลงท้าย `/exec` และ deploy แบบ *Anyone* |
| แก้โค้ด `Code.gs` แล้วไม่มีผล | ต้อง **Deploy → New version** ทุกครั้ง |
| "ยังไม่ได้อนุญาตให้ใช้ตำแหน่ง" | เคยกดปฏิเสธไว้ — แอพจะบอกวิธีเปิดสิทธิ์ตามรุ่นเครื่อง |
| GPS ค้างที่ "กำลังค้นหา" | อยู่ในอาคาร ให้ออกไปที่โล่งแล้วกด *ลองอีกครั้ง* |
| อยู่หน้างานแต่ยังขึ้นว่าอยู่นอกพื้นที่ | รัศมีแคบไป หรือพิกัดหน่วยงานผิด — ตรวจในหน้า admin |
| อัปเดตหน้าเว็บแล้วมือถือยังเห็นของเก่า | ปิดแอพแล้วเปิดใหม่ (`sw.js` ใช้ network-first จะอัปเดตเองรอบถัดไป) |

## หมายเหตุทางเทคนิค

- **JSONP สำหรับอ่าน / POST แบบ `text/plain` สำหรับเขียน** —
  Apps Script ไม่รองรับ CORS preflight การส่งแบบนี้จึงเลี่ยง preflight ไปได้
- **รูปภาพ** ย่อเหลือด้านยาว 1280 px แล้วประทับวันเวลา พิกัด ชื่อหน่วยงาน
  และชื่อพนักงานลงบนรูปก่อนอัปโหลด (ไฟล์เหลือราว 100–300 KB ส่งได้แม้เน็ตช้า)
- **แผนที่** ใช้ Leaflet + OpenStreetMap ไม่ต้องมี API key และไม่มีค่าใช้จ่าย
- **การจับตำแหน่ง** ใช้ `watchPosition` เฝ้าดูต่อเนื่องแล้วเก็บค่าที่แม่นที่สุด
  ไม่ใช่ `getCurrentPosition` ครั้งเดียว — และล้างพิกัดเก่าทุกครั้งที่เข้าหน้าเช็คอินใหม่
  เพื่อไม่ให้ใช้ตำแหน่งของไซต์ก่อนหน้า
