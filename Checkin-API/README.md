# ระบบเช็คอินพนักงานนอกสถานที่ — ฝั่ง API (Google Apps Script)

สคริปต์นี้ทำหน้าที่เป็น **API อย่างเดียว** ไม่ได้ serve หน้าเว็บ
หน้าเว็บอยู่ในโฟลเดอร์ [`docs/`](../docs/) และโฮสต์บน GitHub Pages

## ทำไมต้องแยกหน้าเว็บออกจาก Apps Script

Apps Script Web App ครอบหน้าเว็บไว้ใน `<iframe>` ของ Google
ซึ่ง **บล็อกการขอตำแหน่ง GPS ในหลายเบราว์เซอร์** — เป็นสาเหตุที่แอพเช็คอิน
มักขึ้น error "ระบุตำแหน่งไม่ได้" ทั้งที่พนักงานยืนอยู่หน้างานจริง

แยกออกมาโฮสต์เองแล้ว GPS ทำงานเหมือนเว็บปกติทุกประการ
ส่วน Apps Script ยังทำหน้าที่คุยกับ Google Sheet และ Drive เหมือนเดิม

```
มือถือพนักงาน  →  GitHub Pages (หน้าเว็บ + GPS)  →  Apps Script (API)  →  Google Sheet + Drive
```

## ไฟล์

| ไฟล์ | หน้าที่ |
|------|---------|
| `Code.gs` | API ทั้งหมด — เช็คอิน/เช็คเอาท์, ตรวจพื้นที่, อ่านข้อมูล Dashboard |
| `appsscript.json` | timezone ไทย + สิทธิ์ Sheets/Drive + ตั้งค่า Web App |

## วิธีติดตั้ง

### 1. สร้างโปรเจกต์ Apps Script

1. เปิด <https://script.google.com> → **New project**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางเนื้อหาจากไฟล์ `Code.gs` นี้
3. **⚙️ Project Settings** → ติ๊ก *Show "appsscript.json" manifest file in editor*
   แล้วแก้ไฟล์ manifest ให้ตรงกับ `appsscript.json` นี้

   > อย่าสร้าง `appsscript.json` เป็นไฟล์ `.gs` ใหม่ จะขึ้น error `Unexpected token ':'`

### 2. สร้าง Google Sheet

รันฟังก์ชัน **`setup`** หนึ่งครั้ง (เลือกชื่อฟังก์ชันด้านบน → กด **Run**)

- ครั้งแรกจะขึ้นให้ **Authorize** สิทธิ์ — กดอนุญาตให้ครบ
- ระบบจะสร้าง Google Sheet ใหม่ชื่อ *"ระบบเช็คอินพนักงานนอกสถานที่"* พร้อมแท็บทั้ง 3
- เปิด **View → Logs** จะเห็น **ไอดีของชีต** — คัดลอกไปใส่ในตัวแปร `SPREADSHEET_ID`
  ที่บรรทัดบนสุดของ `Code.gs` แล้วบันทึก

> ถ้ามีชีตที่อยากใช้อยู่แล้ว ให้ใส่ `SPREADSHEET_ID` ก่อน แล้วค่อยรัน `setup()`
> ระบบจะเพิ่มเฉพาะแท็บ/คอลัมน์ที่ยังขาด ไม่แตะข้อมูลเดิม

### 3. ตั้งค่าที่ต้องแก้ก่อนใช้จริง

แก้ที่หัวไฟล์ `Code.gs`

| ตัวแปร | ค่าเริ่มต้น | คำอธิบาย |
|--------|------------|----------|
| `SPREADSHEET_ID` | *(ว่าง)* | ไอดีชีตที่ได้จากขั้นตอนที่ 2 |
| `ADMIN_PIN` | `admin1234` | **ต้องเปลี่ยน** — รหัสเข้าหน้า Dashboard และหน้าตั้งค่า |
| `MAX_ACCURACY_M` | `150` | GPS ที่คลาดเคลื่อนเกินนี้จะไม่รับเช็คอิน |
| `DEFAULT_RADIUS_M` | `200` | รัศมีเริ่มต้นเมื่อไม่ได้ระบุรายหน่วยงาน |
| `GEOFENCE_MODE` | `strict` | `strict` = ระยะห่างต้องไม่เกินรัศมี · `tolerant` = หักค่าคลาดเคลื่อน GPS ให้ก่อน |
| `PHOTO_FOLDER_NAME` | เช็คอินพนักงาน - รูปภาพ | โฟลเดอร์ Drive เก็บรูป (แยกโฟลเดอร์ย่อยรายเดือน) |

### 4. Deploy เป็น Web App

**Deploy → New deployment → Web app**

- Execute as: **Me**
- Who has access: **Anyone**

  > ต้องเป็น *Anyone* เพราะพนักงานเปิดจากหน้าเว็บคนละโดเมน ไม่ได้ล็อกอิน Google
  > การเข้าถึงข้อมูลถูกคุมด้วยรหัสพนักงานและ `ADMIN_PIN` ในตัวสคริปต์แทน

คัดลอก URL ที่ลงท้ายด้วย **`/exec`** ไปใส่ในไฟล์ [`docs/config.js`](../docs/config.js)

> ทุกครั้งที่แก้ `Code.gs` ต้องกด **Deploy → Manage deployments → ✏️ → New version**
> ไม่งั้น URL เดิมจะยังรันโค้ดเวอร์ชันเก่า

## โครงสร้างชีต

### แท็บ `Employees`
| รหัสพนักงาน | ชื่อ-นามสกุล | ตำแหน่ง | สถานะ |
|---|---|---|---|
| 1001 | สมชาย ใจดี | ช่างบริการ | ใช้งาน |

- คัดลอกรายชื่อจากระบบ AppSheet เดิมมาวางได้เลย
- ช่อง **สถานะ** เว้นว่าง = ใช้งานได้ · ใส่ `ปิด` / `พ้นสภาพ` / `ลาออก` = เข้าใช้งานไม่ได้

### แท็บ `Locations`
| รหัสหน่วยงาน | ชื่อหน่วยงาน | ละติจูด | ลองจิจูด | รัศมี(ม.) | ที่อยู่/หมายเหตุ | สถานะ |
|---|---|---|---|---|---|---|
| LOC-001 | บ.เอบีซี จำกัด | 13.756300 | 100.501800 | 200 | สีลม | ใช้งาน |

- กรอกเองในชีตก็ได้ หรือใช้หน้า **admin.html** ปักหมุดจากแผนที่ (สะดวกกว่า)
- **รัศมี** ตั้งได้ต่อหน่วยงาน — เผื่อความคลาดเคลื่อน GPS ไว้อย่างน้อย 50 ม. เสมอ

### แท็บ `CheckLog`

ระบบเขียนให้อัตโนมัติ 23 คอลัมน์ — Log ID, วันที่, พนักงาน, หน่วยงาน,
เวลา/พิกัด/ความแม่นยำ/ระยะห่าง/รูป ทั้งตอนเข้าและตอนออก, ระยะเวลา, หมายเหตุ, สถานะ

## กติกาที่ระบบบังคับ

| เงื่อนไข | เช็คอิน | เช็คเอาท์ |
|---|---|---|
| ต้องอยู่ในรัศมีหน่วยงาน | ✅ บังคับ (บล็อกถ้าอยู่นอกพื้นที่) | ❌ ไม่บังคับ แต่บันทึกพิกัดไว้ |
| ต้องแนบรูปถ่าย | ✅ บังคับ | ❌ ไม่บังคับ |
| ความแม่นยำ GPS | ต้องไม่เกิน `MAX_ACCURACY_M` | ไม่ตรวจ |

การตรวจพื้นที่ทำ **ทั้งฝั่งหน้าเว็บและฝั่งเซิร์ฟเวอร์** — ต่อให้แก้โค้ดในเบราว์เซอร์
เพื่อข้ามการตรวจ ฝั่งเซิร์ฟเวอร์ก็คำนวณระยะห่างใหม่แล้วปฏิเสธอยู่ดี

## ข้อจำกัดที่ควรรู้

- **GPS ปลอม (Fake GPS)** — เว็บแอพกันไม่ได้ 100% แต่ระบบเก็บระยะห่าง
  ความแม่นยำ และรูปถ่ายที่ประทับวันเวลา/พิกัดไว้เป็นหลักฐานประกอบการตรวจสอบ
- **โควต้า Apps Script** — บัญชีฟรีจำกัดเวลารันรวม 90 นาที/วัน
  เพียงพอสำหรับการเช็คอินหลักร้อยครั้งต่อวัน
